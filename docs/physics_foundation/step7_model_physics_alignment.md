# Step 7 — Model–Physics Alignment & Label Integrity

*Physical Foundations, §7. This section closes the gap between the physics (§§1–6) and the three-paradigm
instantiation. It resolves the two integrity threats that would otherwise undermine the ensemble —
**paradigm independence** and **label circularity** — and formalises **coverage-aware fusion**, of which
the thesis's fixed 0.35/0.45/0.20 weighting is the full-coverage special case. Each paradigm is mapped to
the physical signature class it is competent to detect.*

---

## 7.1 Each paradigm detects a distinct physical signature class

The three paradigms are not redundant models of the same thing — they detect **structurally different
kinds of departure**, which is the physical justification for combining them:

| Paradigm | Detects | Physical signature it is competent for | Precursor type (Step 1) |
|---|---|---|---|
| **Random Forest** (S_baseline) | *point* deviation from learned normal | instantaneous multivariate operating point out of range | any mode with a labelled steady signature |
| **LSTM-autoencoder** (S_LSTM) | *temporal* deviation — reconstruction error of a sequence | a *trend* departing from learned dynamics | the gradual precursors (pack-off, bit wear) |
| **DTW** (S_DTW) | *shape* match to a known failure waveform | a characteristic *morphology* regardless of rate/timing | recurring, well-characterised event shapes |

This is a genuine decomposition: a point-anomaly detector, a trend-anomaly detector, and a
shape-matcher answer different questions about the same data. The LSTM carries the **largest weight
(0.45)** because the physics of the headline mechanisms (pack-off, bit wear) is fundamentally a
*trend* problem — a gradual, correlated drift — which is precisely what a sequence reconstruction error
captures. The weighting is therefore physically motivated, not arbitrary: **weight follows the
dominant precursor type**.

---

## 7.2 Integrity threat 1 — paradigm independence (the DTW-from-LSTM trap)

**The problem.** If the DTW reference-pattern library is built *from* the segments the LSTM already
flags as anomalies (e.g. its 99th-percentile reconstruction errors), then S_DTW is not independent
evidence — it is a re-encoding of S_LSTM. Fusing them would **double-count** the same signal and inflate
confidence, defeating the entire purpose of an ensemble (which relies on errors being at least partly
*decorrelated*).

**The resolution — independent provenance for the pattern library.** The DTW reference patterns must
come from a source that does not depend on the LSTM's output:

1. **Physically-defined templates (preferred):** construct reference waveforms from the *mechanism
   physics* of §2 — e.g. the correlated ECD/SPP/torque ramp of a pack-off, the MSE-up/ROP-down crossover
   of bit wear. These are derived from first principles, wholly independent of any learned model.
2. **Externally-labelled events:** waveform segments anchored to *documented* NPT events (daily
   drilling reports), not to model output.
3. **Never** seed DTW from LSTM anomaly windows.

Under (1) or (2), the three paradigms have **independent evidential provenance** — labels (RF),
learned normal dynamics (LSTM), and physics/report-derived templates (DTW) — so their agreement is
meaningful. This independence is a *requirement*, stated in the physics, before any code is written.

## 7.3 Integrity threat 2 — label circularity

**The problem.** If the "anomalous" training labels for the supervised RF are generated by a
*threshold rule* on the same features (e.g. "label anomalous when ECD exceeds X"), and the system is
then evaluated against that same threshold, the model has been trained and tested on its own definition
of truth. It will appear accurate while having learned nothing beyond the threshold — a circularity that
a supervisor will target immediately.

**The resolution — a labelling hierarchy, best available first:**

1. **Documented ground truth (best):** timestamped NPT events from drilling reports. Fully independent.
2. **Physics-consistency labels:** label windows where *multiple independent physical features* cross
   mechanism-specific thresholds *in the correlated pattern the mechanism predicts* (Step 2) — not a
   single-feature cut. This encodes the mechanism, not a tautology, and the correlation requirement makes
   it far harder to game.
3. **Weak/heuristic labels (last resort):** explicitly declared as such, with evaluation reporting that
   the labels are heuristic and results are indicative, not validated.

**The honesty rule:** the label source must be *stated*, and the evaluation must never test against the
same rule that generated the labels. If only (3) is available, the empirical chapter is framed as a
**demonstration of physically-consistent behaviour**, not a validated detector — consistent with the
Step 6 open item.

## 7.4 Coverage-aware fusion (formalising the framework layer)

The thesis fuses three fixed scores: `Risk = 100·(0.35·S_base + 0.45·S_LSTM + 0.20·S_DTW)`. Under the
coverage-aware framework (Conceptual Foundation), this is generalised to fuse **only the monitors that
are active** — observable (their minimum channel set is present, Step 4) and relevant (rig state makes
the mechanism possible, Step 6) — with weights **renormalised over the active set**:

$$\text{Risk}(t) = 100 \cdot \frac{\sum_{k \in \mathcal{A}(t)} w_k\, S_k(t)}{\sum_{k \in \mathcal{A}(t)} w_k}, \qquad \mathcal{A}(t) = \{\text{active monitors at } t\}$$

![Coverage-aware fusion. The fixed-weight fusion (0.35/0.45/0.20) is recovered exactly in the
full-coverage case (left bar). As paradigms or channels drop out, the weights renormalise over the
available set so the risk score stays on a 0–100 scale and remains interpretable — and the system
reports which monitors were active.]({{artifact:03bf52a4-7e48-4d17-be7c-b8be8586f9b8}})

Worked renormalisation (from the base 0.35/0.45/0.20):

| Coverage scenario | Active | Renormalised weights |
|---|---|---|
| Full coverage | RF + LSTM + DTW | 0.35 / 0.45 / 0.20 (**= thesis fixed weights**) |
| No pattern library | RF + LSTM | 0.437 / 0.562 |
| No history/labels | LSTM + DTW | — / 0.692 / 0.308 |
| Sparse channels | LSTM only | 1.00 |

**The fixed-weight fusion is exactly the full-coverage special case** (left bar). This is the precise
sense in which the framework (Layer 1) *subsumes* the instantiation (Layer 2): the thesis's headline
equation is one point in a family, recovered when every monitor is available. Two rules make it honest:

- **Renormalisation** keeps the score on 0–100 and interpretable under any coverage.
- **Coverage reporting:** every score ships with *which* monitors were active and which mechanisms were
  dark — the risk number is never presented without its coverage (Conceptual Foundation §3, link 6).

## 7.5 What this fixes

- **Paradigm independence** is required by construction: DTW templates come from physics or documented
  events, never from LSTM output — so ensemble agreement carries real information.
- **Label integrity** is governed by a stated hierarchy (documented > physics-consistency > weak),
  with the anti-circularity rule that evaluation never reuses the labelling rule.
- **Coverage-aware fusion** is formalised, with the thesis's fixed weights shown to be its
  full-coverage special case — closing the loop between the framework and the instantiation.
- Each paradigm is tied to the physical signature class (point / trend / shape) it is competent for,
  making the 0.45 LSTM weight a physical statement (headline precursors are trend-dominated), not an
  arbitrary tuned constant.
